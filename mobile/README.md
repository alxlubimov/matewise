# Matewise Mobile

Первый прототип на React Native + Expo SDK 57 для iOS и Android. Общий интерфейс также запускается в браузере для проверки сценариев. Русский язык, шрифт Golos Text, контурные иконки и цвета лендинга.

## Что работает

- Поиск людей и готовых комнат карточками: свайп вправо — «В соседи», влево — пропустить. Наклон и подписи показывают действие; кнопки дублируют жесты. Фильтры города и личного бюджета, сохранённые анкеты.
- Анкеты всех будущих соседей, личная доля аренды, фото комнаты и общих зон.
- Группы: текущий состав, свободные места, наличие жилья; учебный сценарий «нас двое — ищем третьего».
- Интерес, подтверждение каждого действующего участника, открытие чата после всех согласий и отдельное подтверждение вступления.
- Чат с подсказками для начала разговора и сохранением сообщений на устройстве.
- Редактирование профиля, проверка возраста 18+, создание своей учебной группы.
- Восстановление профиля, сохранённых анкет, запросов, группы и сообщений после перезапуска.

Это локальное демо: нет реальных аккаунтов или сервера, участникам не отправляются сообщения, объявления и сведения вымышленные. Кнопки подтверждения от имени соседей явно обозначены как учебное управление. В реальном приложении подтверждение разрешено только авторизованному участнику от своего имени. Для аватаров используются инициалы; загружать фотографии пока нельзя.

Свайп вправо сохраняет интерес, но не вступление в группу. Пропущенные карточки можно вернуть; пропуски действуют в текущем сеансе поиска. Отправленные запросы сохраняются на устройстве и доступны во вкладке «Группы». При включённом уменьшении движения карточка сменяется без анимации ухода.

## Запуск на телефоне

Нужен Node.js 22.18+ (рекомендуется 24). Установите Expo Go с поддержкой SDK 57. Телефон и компьютер должны быть в одной сети.

```sh
git clone https://github.com/alxlubimov/matewise.git
cd matewise/mobile
npm ci
npm start
```

На iPhone откройте QR-код камерой, на Android — через Expo Go. Это запуск прототипа, а не установка опубликованного приложения.

На macOS с Xcode можно запустить iOS Simulator через `npm run ios`. Android Emulator требует Android Studio и запускается через `npm run android`. Облачная Linux-среда не предоставляет iOS Simulator; запуска на реальных устройствах здесь не было.

## Проверки

```sh
npm run lint
npm run typecheck
npm test
npm run export:web
npx expo export --platform all --max-workers 2
```

`expo export` создаёт JavaScript/Hermes-бандлы и ресурсы. Он не создаёт подписанные APK/IPA и не проверяет работу на физическом телефоне. Web-сборка находится в `dist`; запускайте `npm run preview:web` для HTTP-сервера с поддержкой перезагрузки внутренних маршрутов. Для браузерной проверки предусмотрены те же основные действия, что в мобильном интерфейсе.

В текущей облачной среде кэш инструментов направляется в доступный каталог:

```sh
npm ci --cache /tmp/matewise-npm-cache
DOTSLASH_CACHE=/tmp/matewise-dotslash-cache EXPO_OFFLINE=1 EXPO_NO_CACHE=1 EXPO_NO_TELEMETRY=1 npx expo start --web --port 8081
```

Флаг `EXPO_OFFLINE=1` использует встроенную в установленный SDK таблицу совместимости и отключает обращения к недоступным внешним API Expo. На своём компьютере обычный `npm start` предпочтительнее. Не создавайте дополнительный Git worktree: каждая облачная задача уже изолирована, используйте существующий checkout.

В облачном Linux-контейнере отдельное настольное окно React Native DevTools не запускается из-за требований Electron к системному sandbox. Это не мешает Metro, браузерной проверке и экспорту бандлов; ограничения sandbox не отключаются.

## Структура

`src/app/` — маршруты Expo Router, `src/components/ScreenFrame.tsx` — оболочка. `src/screens` — экраны. `src/domain` — модели и правила согласий. `src/state` — редьюсер и локальное хранение. `src/data/demo.ts` — учебные данные. Тесты правил групп и сохранения — в `tests`.
