# Matewise

Мобильное приложение на React Native + Expo находится в [mobile](mobile/README.md). Лендинг и приложение запускаются отдельными командами; зависимости приложения устанавливаются в `mobile` через `npm ci`.

Адаптивный рекламный лендинг приложения для поиска соседей. HTML, CSS и JavaScript без внешних зависимостей. Три изображения концепта интерфейса созданы для лендинга: поиск соседа, готовая комната и чат. Первый экран позволяет переключать сценарии, а учебный общий список квартир демонстрирует выбор всеми участниками. В отдельном примере группы можно менять текущий состав, число свободных мест и наличие жилья. Продуктовая логика и гипотезы монетизации описаны в PRODUCT.md.

## Запуск

Требуется Node.js 20.11 или новее (рекомендуется Node.js 24).

```sh
cd /workspace/matewise
npm run dev
```

Сервер слушает порт 3000. Для другого порта: `PORT=8080 npm start`.

## Ссылки для скачивания

Приложение пока не опубликовано: кнопки честно обозначены «Скоро» и показывают сообщение. Когда появятся официальные ссылки, задайте их в объекте `downloads` в `app.js`, обновите подписи кнопок, текст блока скачивания и ответ о запуске в FAQ в `index.html`.

Анкеты вымышленные. Изображения обозначены как концепт интерфейса, а не скриншоты готового приложения. PDF использован как описание концепции. Регистрация, чат и загрузка приложения не реализованы на лендинге.

## Сборка и публикация

Типографика сайта — Golos Text, шрифт хранится локально в `assets/GolosText.ttf` и встраивается в HTML при сборке. Лицензия SIL Open Font License сохранена рядом. Цвета, размеры, интервалы и адаптивные правила собраны в `style.css`: белый фон, графитовый текст, один зелёный акцент и единые контурные SVG-иконки.

После изменений в `style.css`, `app.js` или изображениях запустите `npm run build`. Сборка встраивает стили, скрипт и изображения в `index.html`; повторная сборка безопасна. HTML-разметку редактируйте непосредственно в `index.html`. Не меняйте атрибуты `data-asset` без обновления соответствующих файлов.

Для просмотра или публикации достаточно одного `index.html`: он не требует загрузки дополнительных файлов. Исходные CSS, JavaScript и изображения оставлены для редактирования. `server.mjs` предназначен для локальной разработки.
